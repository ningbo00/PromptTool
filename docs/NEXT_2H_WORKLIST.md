# 下一轮 2 小时工作清单

执行原则：遵从 TDD 和 DDD。每个小任务先补测试或结构规格，再实现，再运行测试；能独立提交的阶段及时提交。

## 目标

完成 Phase 2 主界面第一轮可用化：让主界面形成清晰的「左侧 Prompt 库 / 中间当前 Prompt / 右侧工作流工具」工作台，并降低按钮噪音。

## 任务清单

### 1. 固化当前 Phase 2 布局基线

- 提交当前三栏布局、工具面板和布局规格测试。
- 确保测试通过。

验收：

- Git 有清晰提交。
- `python -m pytest tests` 通过。

### 2. 整理左侧 Prompt 库操作区

- 将左侧按钮从多行散乱按钮整理为分组：
  - 主要操作：新建、编辑、删除。
  - 排序操作：上移、下移。
  - 批量操作：拼接复制、全选、清空。
- 使用布局规格描述这些分组。
- UI 仍保留原功能，不改变业务行为。

验收：

- 领域和布局测试通过。
- 左侧列表区域比之前更清晰。

### 3. 强化右侧工具面板

- 工具卡片分为主要工作流和辅助设置。
- 主工作流：AI 优化、提示词生成器。
- 辅助工具：AI 设置、帮助。
- 每个卡片用更明确的说明文字。

验收：

- 右侧工具入口不再和编辑区混在一起。
- 布局规格测试覆盖工具分组。

### 4. 主界面代码整理

- 将重复按钮/卡片创建逻辑收敛为小函数。
- 保持 UI 层只做展示和事件转发，不新增业务规则。
- 不在本轮重构 AI 优化弹窗或生成器弹窗。

验收：

- `features/prompt_list/widget.py` 可编译。
- 测试通过。

### 5. 提交和总结

- 至少提交一个 Phase 2 进展提交。
- 总结完成项、测试结果、剩余风险。

## 暂不做

- 不重构提示词生成器内部。
- 不引入新的视觉框架。
