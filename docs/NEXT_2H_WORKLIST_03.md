# 下一轮 2 小时工作清单 03

执行原则：继续遵从 TDD 和 DDD。Phase 2 收尾优先保证主界面使用状态清晰；Phase 3 只做信息架构和动作规格准备，不重构 AI 弹窗实现。

## 目标

1. Phase 2 收尾：主界面增加空状态提示、按钮禁用/启用状态、细节 polish。
2. Phase 3 准备：定义 AI 优化弹窗的信息架构和动作分组规格测试。

## 任务清单

### 1. Prompt 操作可用状态

- 在 PromptService 中提供操作可用性：
  - 是否可编辑。
  - 是否可删除。
  - 是否可上移。
  - 是否可下移。
  - 是否可拼接复制。
  - 是否可 AI 优化。
- 先写测试，再实现。

验收：

- 无选择时编辑/删除/AI 优化不可用。
- 第一项不能上移，最后一项不能下移。
- 没有勾选时不能拼接复制。

### 2. 主界面按钮禁用/启用

- 主界面根据 PromptService 的可用状态刷新按钮。
- 选择、新建、删除、移动、勾选、全选、清空后状态同步。
- 不改变原业务行为。

验收：

- UI 可编译。
- 测试通过。

### 3. 空状态提示

- 无 Prompt 时，编辑区显示明确提示。
- 未选择 Prompt 时，编辑区提示用户从左侧选择或新建。
- 有 Prompt 且已选择时显示当前内容。

验收：

- 初始状态更清楚。
- 删除最后一条后状态正确。

### 4. Phase 3 AI 优化信息架构规格

- 新增 AI 优化布局/动作规格对象。
- 定义默认主流程：
  - 优化当前 Prompt。
  - 中文转英文 Prompt。
  - 生成 3 个变体。
- 定义高级工具：
  - AI 评分。
  - 提取关键词。
  - 推荐负面词。
  - 合规检验。
- 定义结果操作：
  - 应用到当前。
  - 另存为新 Prompt。
  - 复制结果。

验收：

- 有规格测试覆盖动作分组。
- 不在本轮重构 AIOptimizeDialog。

### 5. 提交和总结

- 测试通过后提交。
- 汇报提交号、测试结果和 Phase 3 下一步计划。

## 暂不做

- 不改 AI 网络调用。
- 不重排 AIOptimizeDialog 具体 UI。
- 不改提示词生成器。
