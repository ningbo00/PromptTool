# 下一轮 2 小时工作清单 02

执行原则：继续遵从 TDD 和 DDD。先补测试/规格，再实现，再测试，再提交。

## 目标

继续 Phase 2：让主界面更像一个可用的工作台，而不是简单三栏堆叠。优先优化信息反馈、状态显示和按钮密度。

## 任务清单

### 1. Prompt 库状态反馈

- 在领域服务中提供 Prompt 总数、勾选数量、当前选择状态。
- 主界面左侧显示「总数 / 已勾选」状态。
- 不在 UI 中直接计算复杂状态。

验收：

- PromptService 有测试覆盖统计状态。
- 主界面能显示列表状态。

### 2. 编辑区状态反馈

- 中间编辑区标题从单一「预览/编辑中」升级为更明确状态：
  - 未选择 Prompt。
  - 预览当前 Prompt。
  - 编辑中。
- 选择、删除、新建后状态一致。

验收：

- UI 逻辑保持可编译。
- 不破坏保存、复制、选择行为。

### 3. 工具面板细化

- 右侧工具卡片改为更明确的动作文字，而不是统一「打开」。
- AI 优化卡片提示需要先选择当前 Prompt。
- 提示词生成器卡片说明它会新建/插入 Prompt。

验收：

- 工具入口语义清楚。
- 不改变原功能。

### 4. 左侧按钮密度优化

- 保持现有功能，微调按钮文案和排布。
- 避免一组按钮横向挤压过度。

验收：

- 左侧三组操作仍完整。
- 功能回调不变。

### 5. 提交和总结

- 测试通过后提交。
- 汇报提交号、测试结果和下一个清单建议。

## 暂不做

- 不改 AI 优化弹窗内部。
- 不改提示词生成器内部。
- 不做大规模主题系统重构。
