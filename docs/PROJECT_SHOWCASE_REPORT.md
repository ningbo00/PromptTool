# PromptTool 项目展示报告

更新时间：2026-06-04

## 1. 展示主题

PromptTool / Prompt Studio 是一款面向 AI 图像、视频、影视美术、游戏 CG 与创意工作流的本地 Prompt 生产力工具。它把 Prompt 管理、AI 优化、可视化提示词生成、截图反推和自定义风格预设整合到一个 Windows 桌面应用中。

本项目的展示重点不是单一 Prompt 编辑器，而是一个完整的 Prompt 工作台：

- 管理：把常用提示词沉淀为本地资产库。
- 生成：通过结构化参数快速生成高质量提示词。
- 优化：使用大模型改写、评分、翻译和扩展 Prompt。
- 反推：从截图反向分析视觉提示词。
- 复用：通过快捷键、精简模式、自定义预设提升日常生产效率。

## 2. 项目定位

### 2.1 用户痛点

AI 生图和生视频工作流中，常见问题包括：

- Prompt 分散在聊天记录、记事本、网页和历史项目中，难以检索。
- 优秀 Prompt 无法沉淀为可复用资产。
- 参考图分析依赖人工描述，效率低。
- 图片模型、文字模型、不同服务商之间切换繁琐。
- 复杂镜头、光线、构图、风格描述难以稳定组织。
- 团队或个人很难批量制作统一风格预设。

### 2.2 项目解决方案

PromptTool 将这些流程整合为：

- 本地 Prompt 库。
- AI 优化工作台。
- 四步式提示词生成器。
- 截图反推工具。
- JSON 风格预设导入系统。
- 全局快捷键复制系统。

它使 Prompt 从“临时文本”升级为“可维护的创意资产”。

## 3. 核心能力展示

## 3.1 Prompt 本地资产库

能力：

- 新建、编辑、删除 Prompt。
- 搜索 Prompt。
- 按顺序管理 Prompt。
- 勾选多条 Prompt 并拼接复制。
- 选择 Prompt 自动复制。
- 每条 Prompt 可设置全局复制快捷键。

展示话术：

> 这是 PromptTool 的基础资产管理能力。用户可以把常用角色设定、风格词、负面词、镜头描述保存为本地库，并通过搜索和快捷键快速复用。

展示步骤：

1. 新建一条 Prompt。
2. 保存标题和正文。
3. 点击左侧条目，展示右侧内容。
4. 点击复制或直接选择条目自动复制。
5. 设置快捷键后演示全局复制。

## 3.2 顶部主流程入口

当前主流程：

- `提示词生成器`
- `截图`
- `▼` 截图设置
- `AI 优化`

设计特点：

- 主功能靠左并居中呈现。
- 辅助功能靠右：设置、帮助、精简、置顶。
- 视觉语言克制，使用蓝色作为唯一主强调色。
- 适合长期使用的工具软件布局，而不是一次性演示界面。

展示话术：

> 顶部工具栏把最常用的工作流入口放在第一层：先生成、再截图反推、再 AI 优化。设置和帮助被收纳到右侧，不干扰主流程。

## 3.3 AI 优化工作台

能力：

- 优化 Prompt。
- 翻译 Prompt。
- 扩写 Prompt。
- 生成变体。
- AI 评分和建议。
- 关键词提取。
- 负面词推荐。
- 合规检查和修复。

展示话术：

> AI 优化不是简单聊天窗口，而是围绕 Prompt 工作流设计的一组动作按钮。用户不需要每次重新写指令，可以直接对当前 Prompt 进行标准化处理。

展示步骤：

1. 选择一个 Prompt。
2. 打开 AI 优化。
3. 选择一个优化动作。
4. 展示结果。
5. 应用到当前 Prompt 或另存为新 Prompt。

## 3.4 四步式提示词生成器

生成器结构：

1. 场景
2. 风格
3. 镜头
4. 输出

核心价值：

- 把复杂 Prompt 拆解成可调参数。
- 降低镜头、光线、构图、材质、风格词的组织成本。
- 同时输出英文 Prompt 和中文参数解释。
- 支持负面词和正面排除词转换。

展示话术：

> 提示词生成器适合从零构建高质量生图/生视频 Prompt。它把影视摄影语言、风格预设、光线方向、输出质量等拆成可以逐步调整的模块。

展示步骤：

1. 输入主体和环境。
2. 选择风格预设。
3. 调整镜头、光源和角度。
4. 设置输出质量和比例。
5. 生成并插入主 Prompt 列表。

## 3.5 截图反推 Prompt

截图反推是项目的重要亮点。

能力：

- 点击截图后自动隐藏主窗口。
- 支持框选任意屏幕区域。
- 支持 Esc / 右键取消。
- 高 DPI 截图坐标映射修复。
- 支持不同反推用途。
- 支持完整/精简提示词。
- 输出英文 Prompt 和中文预览。

反推模式：

- 完整反推
- 角色反推
- 场景反推
- 镜头语言
- 光色分析
- 服装道具
- 构图版式
- 负面词反推
- 自定义

展示话术：

> 截图反推可以把任何参考图变成可编辑、可保存、可复用的 Prompt。用户可以先在截图设置中选择用途，比如只分析角色、只分析场景、只分析镜头语言，然后再框选截图。

展示步骤：

1. 点击 `▼` 设置为 `角色反推`。
2. 选择 `精简提示词`。
3. 点击 `截图`。
4. 框选一张角色参考图。
5. 展示生成结果：English Prompt + 中文预览。
6. 结果自动保存到左侧 Prompt 库。

## 3.6 自定义风格预设 JSON

能力：

- 提供豆包写实模板。
- 提供豆包卡通模板。
- 支持复制模板给大模型。
- 支持从剪贴板导入大模型返回的 JSON。
- 自动区分 `realistic` 与 `cartoon`。
- 导入后自动出现在对应预设区。

展示话术：

> 用户不需要手写复杂 JSON。软件内置一段固定提示词模板，复制给豆包后，只需要补充主题，比如“曼达洛人风格”“赛博江户城市”“皮克斯式游戏 CG”，豆包返回的 JSON 可以直接导入软件成为新预设。

展示步骤：

1. 打开提示词生成器。
2. 进入风格预设。
3. 点击 `复制写实模板`。
4. 粘贴给豆包并输入主题。
5. 复制返回 JSON。
6. 点击 `从剪贴板导入预设`。
7. 展示新预设出现在预设区。

## 3.7 精简模式

能力：

- 主窗口收起。
- 显示小型悬浮 Prompt 列表。
- 可拖动移动。
- 点击 Prompt 快速复制。
- 点击恢复返回主窗口。

展示话术：

> 精简模式适合把 PromptTool 放在绘图软件、视频生成网页或浏览器旁边，像一个小型提示词抽屉，随时点击复制。

## 4. 界面设计展示

### 4.1 设计方向

当前 UI 方向：

- 深色专业工具风。
- 接近 VSCode 的克制蓝色强调。
- 避免花哨渐变和过强装饰。
- 优先保证长期工作可读性。
- 主要按钮小型化，减少界面压迫感。

### 4.2 信息架构

主界面：

- 顶部：主流程入口。
- 左侧：Prompt 库。
- 右侧：编辑与预览。

生成器：

- 分步骤组织复杂参数。
- 每一步只暴露相关控制项。
- 右侧/底部展示生成结果。

AI 优化：

- 按动作分组。
- 减少自由输入依赖。
- 保持结果可应用、可另存。

截图设置：

- 先选择用途，再截图。
- 避免每次截图后再问用户想分析什么。

## 5. 技术架构展示

### 5.1 技术栈

- Python 3.12
- PySide6
- PyInstaller
- pytest
- Windows RegisterHotKey
- 本地 JSON 存储

### 5.2 架构分层

项目结构上分为：

- `features/`：功能 UI 模块。
- `core/`：领域逻辑与服务。
- `infrastructure/`：JSON 存储适配。
- `shared/`：配置、UI Kit、Qt 兼容层、全局快捷键。
- `tests/`：自动化测试。

### 5.3 关键模块

- `features/prompt_list/widget.py`：主窗口。
- `features/camera_builder/widget.py`：提示词生成器。
- `features/ai_optimize/widget.py`：AI 优化窗口。
- `features/screenshot_prompt/widget.py`：截图选择和视觉模型调用。
- `features/screenshot_settings/widget.py`：截图分析设置。
- `shared/qt_compat.py`：Tk-like API 到 PySide6 的兼容层。
- `shared/global_hotkeys.py`：Windows 全局快捷键。
- `core/services/custom_preset_service.py`：自定义 JSON 预设导入。

## 7. 项目亮点总结

### 7.1 从 Prompt 文本到 Prompt 资产

传统方式是把 Prompt 散落在聊天记录或文档里。PromptTool 把它们变成可搜索、可编辑、可快捷调用的资产库。

### 7.2 截图反推让参考图进入工作流

用户可以直接从任意屏幕内容反推 Prompt，并指定分析维度。它降低了从参考图到生成提示词的门槛。

### 7.3 生成器沉淀影视美术经验

镜头、光线、材质、风格、负面词被拆成结构化参数，便于复用和调整。

### 7.4 大模型辅助制作预设

通过固定 JSON Schema 和豆包模板，用户可以让大模型批量或定向生成风格预设，再导入软件复用。

### 7.5 本地优先

Prompt 数据、配置、自定义预设都保存在本地 JSON，适合个人离线管理和长期维护。

## 8. 推荐展示脚本

### 开场

> 这是一个本地 Prompt 工作台，目标是把 AI 生图、生视频过程中散乱的 Prompt 管理、优化、生成和截图反推整合到一个桌面工具里。

### 第一步：Prompt 库

> 左侧是本地 Prompt 资产库，可以搜索、新建、编辑、复制、拼接，也可以给每条 Prompt 设置全局快捷键。

### 第二步：生成器

> 如果不是从已有 Prompt 开始，可以进入提示词生成器。它按场景、风格、镜头、输出四步生成结构化 Prompt。

### 第三步：AI 优化

> 生成或保存后的 Prompt 可以继续交给 AI 优化，执行翻译、扩写、评分、变体生成、负面词推荐等动作。

### 第四步：截图反推

> 如果用户有参考图，可以选择截图反推。这里可以先设置分析用途，比如角色、场景、镜头语言，然后框选任意屏幕区域，生成英文 Prompt 和中文预览。

### 第五步：自定义预设

> 对于长期使用的电影、游戏、卡通或 CG 风格，可以复制软件内置模板给豆包，让豆包生成 JSON，导入后就成为自己的风格预设。

### 收尾

> PromptTool 的目标不是替代大模型，而是把大模型生成能力变成稳定、可复用、可管理的本地生产力流程。

## 9. 当前边界与后续方向

当前边界：

- AI 调用依赖用户自己的 API Key。
- 截图反推质量取决于所选视觉模型。
- 自定义预设需要大模型严格返回合法 JSON。
- 当前重点平台是 Windows 桌面。

后续可扩展方向：

- Prompt 标签系统。
- Prompt 分组/项目空间。
- 多语言 UI。
- 预设市场或预设包导入导出。
- 截图结果历史记录。
- 更强的图像分析模板管理。
- 更完善的视觉 QA 截图报告。

## 10. 一句话总结

PromptTool 是一个把 Prompt 管理、AI 优化、截图反推和风格预设制作结合起来的本地 AI 创意工作台，适合需要长期沉淀和复用 Prompt 的个人创作者与小型团队。
