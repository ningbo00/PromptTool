# PromptTool / Prompt Studio 项目简介与使用说明

更新时间：2026-06-04

## 1. 项目简介

PromptTool（界面名：Prompt Studio）是一个面向 AI 生图、生视频、影视美术和创意工作流的本地桌面 Prompt 工具。它用于管理提示词、快速复制常用 Prompt、通过 AI 优化文本、通过可视化参数生成摄影机/风格提示词，并支持截图反推提示词。

项目当前已经完成从原 Tkinter 形态向 PySide6 桌面界面的迁移。界面风格采用克制的深色工具软件设计，整体接近 VSCode 类成熟生产力工具：低饱和暗色背景、蓝色作为唯一主要强调色、紧凑按钮、面板化信息结构。

核心目标：

- 本地管理 Prompt，不依赖云端数据库。
- 快速保存、搜索、编辑、复制、拼接提示词。
- 用 AI 对 Prompt 进行优化、翻译、扩写、评分、合规修复。
- 用“提示词生成器”按场景、风格、镜头、输出四步生成高质量 Prompt。
- 用截图反推功能，从任意屏幕区域生成英文 Prompt 与中文预览。
- 支持全局快捷键，即使应用不在前台也可以快速复制 Prompt。
- 支持自定义风格预设 JSON 导入，方便用大模型批量或定向制作风格预设。

## 2. 适用场景

PromptTool 适合以下工作流：

- AI 生图：Midjourney、Stable Diffusion、豆包、通义万相、即梦等图像生成工具的提示词整理。
- AI 生视频：镜头语言、场景描述、角色风格、负面词等视频提示词构建。
- 影视美术：快速沉淀电影感、镜头、光影、色彩、材质、风格预设。
- 游戏 CG / 动画设计：保存角色、场景、卡通、二次元、3D 动画风格提示词。
- 创意团队：把常用 Prompt 变成可搜索、可复用、可组合的本地素材库。
- 逆向分析：框选参考图、网页、作品截图后，让视觉模型反推 Prompt。

## 3. 快速启动

### 3.1 使用打包版

打包后的 Windows 可执行文件位于：

```text
G:\PromptTool_Qt\dist\PromptTool.exe
```

双击 `PromptTool.exe` 即可运行。

首次运行时：

- 如果没有 `prompts.json`，会从空 Prompt 库开始。
- AI 服务商、API Key、截图模型、快捷键等配置会保存到 `ai_config.json`。
- 自定义预设会保存到 `custom_presets.json`。

### 3.2 使用源码运行

在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

### 3.3 重新打包

```powershell
python -m PyInstaller --clean --noconfirm PromptTool.spec
```

打包产物会生成到：

```text
dist\PromptTool.exe
```

## 4. 主界面说明

主界面分为顶部工具栏、左侧 Prompt 库、右侧编辑区。

### 4.1 顶部工具栏

主要入口：

- `提示词生成器`：打开四步式提示词生成器。
- `截图`：隐藏主窗口后进入屏幕框选，用视觉模型反推 Prompt。
- `▼`：截图设置副按钮，用于选择截图反推用途与输出长度。
- `AI 优化`：对当前选中 Prompt 做 AI 优化。

辅助入口：

- `设置`：配置 AI 服务商、API Key、文字模型、截图模型、截图快捷键。
- `帮助`：查看帮助信息。
- `精简`：进入迷你浮窗模式，方便悬浮在其他软件旁边快速复制 Prompt。
- `置顶`：让主窗口保持在其他窗口上方。

### 4.2 左侧 Prompt 库

功能：

- 搜索 Prompt。
- 查看所有已保存提示词。
- 勾选多条 Prompt。
- 新建、编辑、删除、上移、下移。
- 拼接复制多条已勾选 Prompt。

常用操作：

1. 点击 `+ 新建`。
2. 在右侧输入标题和正文。
3. 点击 `保存`。
4. 单击左侧 Prompt 会显示内容，并自动复制正文。
5. 勾选多条后点击 `拼接`，会用空行拼接并复制。

### 4.3 右侧编辑区

字段：

- `Title`：Prompt 标题。
- `Shortcut`：该 Prompt 的全局复制快捷键。
- 正文区域：Prompt 内容。

按钮：

- `保存`：保存标题、正文和快捷键。
- `复制`：复制当前 Prompt 正文。

## 5. 全局快捷键

PromptTool 支持 Windows 全局快捷键。

### 5.1 截图快捷键

在 `设置` 中可以配置截图快捷键，默认类似：

```text
Ctrl+Shift+S
```

使用时即使 PromptTool 不在前台，也可以触发截图反推。截图时主窗口会先隐藏，避免只能截到本软件窗口。

### 5.2 Prompt 快捷键

每条 Prompt 可以单独设置快捷键，例如：

```text
Ctrl+Alt+1
F8
F9
```

保存后，在任意窗口按下该快捷键，会把对应 Prompt 复制到剪贴板。

快捷键冲突规则：

- 不能和截图快捷键重复。
- 不能和其他 Prompt 的快捷键重复。
- 如果系统占用某个快捷键，状态栏会提示注册失败。

## 6. 截图反推 Prompt

截图反推是当前项目的重要功能。它适合从参考图、网页、影视画面、游戏截图、CG 图、角色设计图中反向提取 Prompt。

### 6.1 基本流程

1. 在顶部点击 `▼` 打开截图设置。
2. 选择反推用途。
3. 选择生成长度：`完整提示词` 或 `精简提示词`。
4. 可选：输入自定义分析要求。
5. 点击顶部 `截图` 或按截图快捷键。
6. 框选屏幕区域。
7. 等待视觉模型分析。
8. 分析结果会作为新 Prompt 加入左侧列表。

### 6.2 支持的反推用途

- `完整反推`：生成完整图像/视频生成 Prompt。
- `角色反推`：分析角色外观、服装、材质、道具、气质。
- `场景反推`：分析环境、建筑、空间层次、氛围和世界观。
- `镜头语言`：分析景别、角度、构图、镜头倾向、景深。
- `光色分析`：分析主光、辅光、轮廓光、色温、调色、对比。
- `服装道具`：分析服装层次、盔甲、武器、饰品、材质、磨损。
- `构图版式`：分析视觉层级、主体位置、留白、引导线、海报式布局。
- `负面词反推`：生成用于避免画面缺陷或风格偏差的 negative prompt。
- `自定义`：按用户输入的要求分析截图。

### 6.3 完整提示词与精简提示词

- `完整提示词`：信息更全，适合保存、二次编辑、生视频或复杂图像生成。
- `精简提示词`：更短，更适合直接用于图片生成，避免过长句子。

### 6.4 输出格式

截图生成结果会要求模型输出：

```text
English Prompt: ...

中文预览：...
```

如果模型没有返回中文预览，程序会自动补一个中文预览占位，避免结果结构缺失。

## 7. AI 设置

点击顶部 `设置` 进入 AI 设置窗口。

支持服务商：

- Kimi / Moonshot
- 阿里百炼 / Qwen
- 豆包 / 火山方舟
- DeepSeek
- OpenAI / ChatGPT

配置内容：

- 文字 AI 服务商
- 文字模型
- API Key
- 截图专用服务商
- 截图专用模型
- 截图快捷键

注意：

- 文字优化模型和截图模型是分开的。
- 截图分析需要支持图片输入的视觉模型。
- 项目允许为截图选择独立模型，避免文字模型不支持图片导致失败。

## 8. AI 优化

AI 优化用于对当前选中的 Prompt 做二次处理。

常见动作：

- 优化当前 Prompt。
- 中文转英文。
- 英文转中文。
- 扩写。
- 生成多个变体。
- 打分并给建议。
- 提取关键词。
- 推荐负面词。
- 合规检查。
- 根据评分继续改进。

使用流程：

1. 在左侧选择一个 Prompt。
2. 点击顶部 `AI 优化`。
3. 选择优化方向。
4. 点击对应动作。
5. 将结果应用到当前 Prompt，或另存为新 Prompt。

## 9. 提示词生成器

提示词生成器是一个四步式 Prompt 构建器，适合从零生成结构化生图/生视频提示词。

### 9.1 四步结构

1. `场景`：主体、环境、角色、天气、场景词块。
2. `风格`：预设、情绪、美学、滤镜、动画风格提炼。
3. `镜头`：景别、镜头、角度、主光、轮廓光、摄影参数。
4. `输出`：质量、细节、渲染、比例、负面词。

### 9.2 预览输出

生成器会展示：

- 英文正面 Prompt。
- 中文参数解释。
- 英文负面 Prompt。
- 中文负面词解释。

### 9.3 常用操作

- `生成`：根据当前参数刷新结果。
- `复制`：复制正面 Prompt。
- `插入列表`：保存为主界面 Prompt。
- `转为正面排除词`：把负面词转换为正面描述中的排除要求。

## 10. 自定义预设 JSON 导入

PromptTool 支持用豆包或其他大模型生成可导入的风格预设 JSON。

### 10.1 制作流程

1. 打开 `提示词生成器`。
2. 进入 `风格` -> `预设`。
3. 点击 `复制写实模板` 或 `复制卡通模板`。
4. 把模板粘贴给豆包，并补充你想要的主题，例如“星球大战风格的曼达洛人视觉语言”。
5. 豆包返回 JSON。
6. 复制 JSON。
7. 回到 PromptTool，点击 `从剪贴板导入预设`。
8. 导入成功后，新预设会出现在写实或卡通预设区。

### 10.2 JSON 预设分类

预设通过字段区分类型：

```json
{
  "preset_mode": "realistic"
}
```

或：

```json
{
  "preset_mode": "cartoon"
}
```

- `realistic`：写实、电影、摄影、真人 CG。
- `cartoon`：卡通、动画、游戏 CG、二次元、风格化 3D。

### 10.3 预设应该包含什么

应该包含：

- 可复用视觉语言。
- 服装、材质、建筑、道具、世界观倾向。
- 长期稳定的摄影语言。
- 色彩、光影、材质。
- 氛围和情绪。
- 负面词。

不应该包含：

- 一次性剧情。
- 固定角色动作。
- 固定镜头运动路径。
- 具体演员脸。
- 具体版权角色名作为核心 Prompt。
- 只能用于一次视频分镜的临时信息。

## 11. 精简模式

点击主界面 `精简` 可以进入迷你浮窗。

适合场景：

- 在浏览器、绘图软件、视频生成平台旁边悬浮使用。
- 快速点击 Prompt 并复制。
- 不希望主窗口占用太多屏幕空间。

当前精简窗口特性：

- 固定小尺寸浮窗。
- 顶部可拖动移动。
- `恢复` 按钮可返回主界面。
- 列表保留 Prompt 快速点击复制能力。

## 12. 数据文件说明

常见文件：

- `prompts.json`：本地 Prompt 库。

- `custom_presets.json`：用户导入的自定义风格预设。

这些文件通常不应提交到 Git，尤其是包含 API Key 的配置文件。

## 14. 常见问题

### 14.1 截图没有返回结果

检查：

- 截图服务商 API Key 是否填写。
- 截图模型是否支持图片输入。
- 网络是否可访问对应服务商。
- 是否选择了截图专用模型，而不是只配置了文字模型。

### 14.2 全局快捷键不生效

检查：

- 是否和系统快捷键冲突。
- 是否和截图快捷键冲突。
- 是否和其他 Prompt 快捷键冲突。
- 状态栏是否提示注册失败。

### 14.3 AI 优化失败

检查：

- API Key 是否有效。
- 模型名是否正确。
- 服务商接口是否可用。
- 网络是否正常。

### 14.4 导入预设失败

检查：

- 剪贴板中是否是合法 JSON。
- JSON 是否包含 `schema`、`type`、`preset_mode`、`id`、`label` 等字段。
- `preset_mode` 是否是 `realistic` 或 `cartoon`。
- 数组字段是否真的是字符串数组。

## 15. 推荐工作流

### 15.1 快速生图

1. 用截图反推参考图。
2. 选择 `精简提示词`。
3. 生成后复制 English Prompt。
4. 粘贴到生图工具。

### 15.2 保存风格资产

1. 使用提示词生成器创建风格。
2. 调整镜头、光线、材质。
3. 插入 Prompt 列表。
4. 设置快捷键。
5. 后续在任意软件中一键复制。

### 15.3 制作电影/游戏风格预设

1. 点击 `复制写实模板` 或 `复制卡通模板`。
2. 粘贴给豆包并填写主题。
3. 复制豆包返回 JSON。
4. 在 PromptTool 中导入。
5. 后续在提示词生成器中直接使用该风格。
